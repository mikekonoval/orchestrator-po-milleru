# План фаз

Заполни список фаз. Скрипт `run-all.sh` идёт по строкам в порядке, для каждой `[ ]` запускает `run-phase.sh N`. Закрытые фазы помечаются `[x]` автоматически.

Формат строки строгий: `- [ ] Фаза N: краткое описание`. Регистр и пробелы важны — иначе скрипт строку не распознает.

## Фазы

- [ ] Фаза 1: <что делаем в первой фазе>
- [ ] Фаза 2: <что делаем во второй фазе>
- [ ] Фаза 3: <...>

## Резюме фаз

После закрытия фазы оркестратор добавляет сюда блок: что сделано, ключевые решения, ссылки на файлы отчётов внутри `phase{N}/` (`errors.md`, `missing.md`, `review.md`, `security.md`, `final_check.md`).
