## Что проверить

По следующему чек-листу. По каждому пункту дай вердикт: **OK** / **починить — что** / **не применимо**.

- **Принципы из `idea/05-principles/`** — фаза не нарушает ни один из заявленных принципов (PII, локация хостинга, согласие пользователя и т.д.). Это первичная проверка.
- **ОПАСНАЯ ТРОЙКА** — личные данные + чужой контент + отправка наружу. Если все три сошлись в одном месте — критично, нужно разделять.
- **SQL/NoSQL injection** — ввод пользователя в запрос без параметризации.
- **XSS** — пользовательский контент в HTML/DOM без эскейпа.
- **CSRF** — мутирующие запросы без токена/проверки origin.
- **SSRF** — пользователь указывает URL, который сервер дёргает.
- **Утечки токенов в логи** — секреты, ключи, JWT в console.log / stderr / log-файлах.
- **`.env` в коде или коммитах** — секреты в репо.
- **Права на API** — авторизация на эндпоинты, не только аутентификация.
- **Rate limiting** — на критичных эндпоинтах (логин, регистрация, рассылка, дорогие операции).
- **Валидация входов** — типы, длины, форматы, инъекции спецсимволов.
