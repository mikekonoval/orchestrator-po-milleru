## Что сделать

По каждому пункту с пометкой «починить» докажи: **реальная угроза в нашем проекте или паранойя?**

Учитывай:
- Кто пользователь по `idea/03-audience/` — внутренний/анонимный/доверенный.
- Какие данные мы трогаем (публичные/персональные/платёжные) по `architecture/03-данные/`.
- Surface area по `architecture/05-интеграции/` — закрытое API внутри VPN или публичный эндпоинт.
- Принципы из `idea/05-principles/` — нарушение принципа = автоматически реальная угроза.
- Текущий этап — десятки пользователей на старте, не миллионы атакующих.

Если угроза реальна — пометь `РЕАЛЬНАЯ`. Если для эксплуатации нужны условия, которых у нас нет (например, мы не принимаем чужой контент → XSS неактуален, мы внутри VPN → CSRF паранойя) — `ПАРАНОЙЯ`.
